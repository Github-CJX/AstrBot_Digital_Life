# M2.6e 验证记录：追问回看（bili.watch at=秒）

日期：2026-11-26。提交：4c94318。前置：M2.6d（5825/592ad4c 看画面管线）。

## 需求

看完视频后她追问「刚才那里/第 X 秒什么样」时，能按时间戳回看那一小段画面，
而不是只能整体重看一遍。借鉴 dsh-watch-along 的「事件流 + 按需回取」思路的
最小落地：固定 6 帧全片拼图之外，增加以时刻为中心的窗口回看。

## 实现

- `digital_life_core/conversation/bili_tools.py`：
  - `bili.watch` 参数新增可选 `at`（秒，0–86400；bool/负数/超界拒绝）；
  - `at` 非空 → mode=`look`：只取该时刻附近的画面（video_info + sight），
    不拉字幕/热评/弹幕（轻量材料）；
  - sight 新增 `changes`：画面突变点 `[{"at","score"}]`（≤6 条，畸形项丢弃）；
  - `_validate_sight` 统一校验 video/look 两种模式的 sight；
  - INSTRUCTION 与 ToolSpec 描述加入回看用法。
- `digital_life_host/bili_see.py`：
  - `describe(port, bvid, *, at=None)`：at 模式探针带以 at 为中心（宽度 ≤24s，
    按时长收边，不越界），其余流程（变化选帧→拼图→视觉）不变；
  - `_change_peaks`：相邻候选帧变化分取前 3 突变点（回看模式只留窗口内）；
  - 回看提示词标注「（回看：第 X 秒附近的连续画面）」。

## 真实环境验收项

1. 看完一个视频后私聊问「刚才第 30 秒那里是什么画面」，她应调用
   `bili.watch {target: BV号, at: 30}` 并用回看描述回答（画面仅覆盖该时刻附近）。
2. 问画面突变点：「哪个地方画面切得最猛」→ sight.changes 时间点应被复述。
3. `at` 传非法值（如 at=abc）时应报参数错误而不是整轮失败。
4. 回看失败（视频不可匿名播放）时如实说看不了，不编造画面。
