# M2.1 验证记录：模块开关（2026-11-25）

M2 第一步：把「保留 8 / 可选 6 / 移除 4」的处置落成运行期开关。本批只做**注册与调度的启停**，不删除任何实现：关闭之后历史数据仍可只读查询，重新打开即可恢复。

## 1. 三类模块与默认值

| 类别 | 模块 | 默认 |
| --- | --- | --- |
| 保留 | `content`（阅读与创作）、`reality`（现实触及底座）、`together`（一起做事的底座） | 开，开关关不掉 |
| 可选 | `game`、`image`、`workspace`、`multi_role`、`phone`、`screen` | 关 |
| 移除 | `live`、`qzone`、`mihome`、`huawei_health` | 关 |

来源：`docs/digital-life/FEATURE_REQUIREMENTS.md` 的模块处置表。

## 2. 开关实现

新增 `digital_life_host/module_gates.py`：

- 常量 `RETAINED_MODULES` / `OPTIONAL_MODULES` / `REMOVED_MODULES` / `ALL_MODULES` / `DEFAULTS`；`DEFAULTS` 只给保留项 `True`。
- 解析顺序 **环境变量 > 开关文件 > 内置默认**：
  - 环境变量 `DIGITAL_LIFE_MODULE_<NAME>=1`（大写；`0/false/no/off/disable/disabled/空` 视为关闭）。
  - 开关文件：插件数据目录下 `digital_life_modules.json`，形如 `{"modules": {"image": true, "qzone": false}}`；只认已知模块名，坏文件只告警回默认。
- API：`configure_modules(settings_root)`（启动时记根目录）、`resolved()`、`module_enabled(name)`、`enabled_modules(names)`（按传入顺序过滤）、`describe()`。
- **不缓存**解析结果：开关文件很小，缓存会让运行期改开关、测试里改环境变量读到过期值（第一版带缓存，`test_environment_enables_optional_module` 因此失败，已去掉）。

## 3. 四处闸门

| 位置 | 改动 |
| --- | --- |
| `main.py` | `__init__` 里 `configure_module_gates(data_root)` 并打一行 `[CompanionV2][modules] …` 日志；`initialize()` 的 QQ 空间发布器改为 `module_enabled("qzone")` 才创建 |
| `digital_life_host/native_extensions/builtins.py` | `create_bundled_extensions` 里 `names = list(enabled_modules(names))`，未开启的模块连 provider 都不创建 |
| `digital_life_host/native_extensions/reality/activity_methods.py` | `_init_embedded_mihome` 在 `mihome` 关闭时直接把三个米家句柄置 `None` 并返回 |
| `digital_life_host/multi_api.py`、`web_api.py`、`multi_session.py` | `HuaweiHealthWebAPI` 路由与健康素材注入都先过 `module_enabled("huawei_health")` |

`game`、`image`、`screen`、`workspace`、`multi_role`、`phone` 的注册都经由 `create_bundled_extensions`，因此第一步只需这一处过滤；`live` 同样只在这里注册。`qzone`、`mihome`、`huawei_health` 有独立的启动/挂载路径，单独加闸。

## 4. 测试

新增 `tests/test_m2_module_gates.py`（17 例）：

- `ModuleDefaultsTests`：保留项开、可选/移除项关、未知模块名视为开（不误伤未来模块）、`DEFAULTS` 覆盖 `ALL_MODULES`、`describe()` 列出关闭项。
- `ModuleOverrideTests`：环境变量开可选、关保留、四种「假值」写法、开关文件生效、环境变量压过文件、坏文件回默认、未知 key 忽略、`configure_modules` 之后无参生效。
- `ModuleFilterTests`：`enabled_modules(("content","image","screen","reality","together","game","live")) == ("content","reality","together")`；环境变量开启后 `game` 恢复。
- `BundledExtensionGateTests`：patch `builtins.create_bundled_extension`，断言默认只创建 `content/reality/together`，`issues` 为空。

新增 `tests/conftest.py`：老套件按「用户显式开启全部可选模块」的全功能安装跑——session 级 autouse fixture 用 `DIGITAL_LIFE_MODULE_*` 环境变量打开全部开关；`test_m2_module_gates.py` 用文件内 autouse fixture 摘掉这组变量，单独验证默认值。

## 5. 测试证据（一次性容器，`--network none`，镜像 `soulter/astrbot:latest`）

命令：

```
docker run --rm --network none -m 1100m \
  -v /opt/astrbot-dl/data/plugins/astrbot_plugin_digital_life:/AstrBot/data/plugins/astrbot_plugin_digital_life:ro \
  -w /AstrBot/data/plugins/astrbot_plugin_digital_life \
  -e PYTHONDONTWRITEBYTECODE=1 soulter/astrbot:latest \
  python -m pytest -q -p no:cacheprovider --tb=line tests/ \
  --ignore=tests/test_care_engine.py --ignore=tests/test_mihome_control_profiles.py \
  --ignore=tests/test_mihome_home_care.py --ignore=tests/test_mihome_qr.py
```

（四个 `--ignore` 是环境缺 `mijiaAPI` 导致的**收集期**导入失败，与本次改动无关。）

分批结果：

- `tests/test_m2_module_gates.py`：**17 passed**（1.3s）。
- 未加 `conftest.py` 前跑 `test_native_provider_sessions.py + test_product_integration.py`：6 + 6 failed —— 这些用例直接断言「七类内置 provider 都在场」，开关默认关后自然不成立。
- 加 `conftest.py` 后同样两套件：**4 failed, 21 passed**。
- 残留 4 个失败与开关**无关**：把 `native_extensions/builtins.py`、`reality/activity_methods.py`、`main.py` 换成 `git show HEAD:` 原文（不打补丁）后，同 4 例仍然失败（`False is not true` / `'companion.screen.native' != 'image'` / `KeyError: 'code'` / `True is not false`），与 M1.1 记录的三个基线既有失败同类，属环境漂移。

## 6. 部署注意（测试服务器）

容器重启前必须写开关文件，否则生图模块会被默认关掉：

```
/opt/astrbot-dl/data/plugin_data/astrbot_plugin_digital_life/digital_life_modules.json
{"modules": {"image": true}}
```

本机已写入该文件并重启容器，启动日志：

```
[CompanionV2][modules] content,game,huawei_health,image,live,mihome,multi_role,phone,qzone,reality,screen,together,workspace | off=game,huawei_health,live,mihome,multi_role,phone,qzone,screen,workspace
```

即：保留三项 + `image` 开，其余按默认关。
