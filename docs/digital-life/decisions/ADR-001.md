# ADR-001 — 独立 Fork 与数据隔离
- 采用独立插件 ID `astrbot_plugin_digital_life`，Python 包 `digital_life_core` / `digital_life_host`，独立配置名、日志和 HTTP 前缀。
- 继续使用现有 DB schema（v69）及内部协议，暂不导入原插件数据。原始压缩包不改。
- `storage_location.py` 取消旧同级数据根自动查找，改独立存储指针/owner 格式；`fork_guard.py` 校验目录名。
- 仍有旧公共 API、事件标记、宿主全局 hook 和第三方兼容桥；不承诺双插件共存。使用独立测试宿主。
- 本地 Git 首次提交仅代表用户提供的快照，不是上游真实 Git SHA。
